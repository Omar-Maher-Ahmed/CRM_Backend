# 🚀 نظرة عامة على المشروع وما تم إنجازه (Project Progress & Overview)

## 📌 ملخص الإنجازات
تم الانتهاء من بناء الهيكل المعماري الأساسي لقاعدة البيانات والواجهة البرمجية (GraphQL API) لتطبيق إدارة علاقات العملاء (CRM).

تم تقسيم المشروع إلى مجموعة من الـ **Modules** المستقلة، كل منها مسؤول عن وظيفة محددة لضمان قابلية التوسع والصيانة (Scalability & Maintainability).

### 🏗️ الأنظمة التي تم الانتهاء منها:
1. **نظام المستخدمين والمصادقة (Auth & Users):**
   - تسجيل الدخول (Login) وإصدار JWT.
   - إدارة المستخدمين (إضافة، تعديل، حذف، تغيير كلمة المرور).
   - بناء هيكل هرمي للموظفين (Manager -> Employees).
2. **نظام الأدوار (Roles):**
   - تحديد صلاحيات ومسميات وظيفية (Admin, Employee, إلخ).
3. **نظام العملاء (Customers):**
   - تسجيل بيانات العملاء وربطهم بالموظفين المسؤولين عنهم.
4. **نظام إدارة المبيعات (Sales & Deals):**
   - **المنتجات (Products):** إدارة المنتجات المعروضة للبيع وأسعارها.
   - **مراحل الصفقات (Deal Stages):** مسارات المبيعات (New, Negotiation, Closed).
   - **الصفقات (Deals):** ربط العميل بالموظف وبمرحلة الصفقة.
   - **تفاصيل المنتجات داخل الصفقة (Deal Products):** جدول مفصل يحسب الكميات والسعر الفرعي والإجمالي لكل منتج في الصفقة.
5. **سجل الأنشطة (Activities):**
   - تسجيل ومتابعة كافة الإجراءات والأنشطة المرتبطة بصفقة أو منتج أو موظف.

## 🛠️ التقنيات المستخدمة
- **إطار العمل:** NestJS (Node.js).
- **قواعد البيانات:** PostgreSQL مع TypeORM.
- **لغة الاستعلام:** GraphQL (Code-first approach مع Apollo).
- **لغة البرمجة:** TypeScript.

## 🚧 النواقص والخطوات القادمة
1. إضافة حماية للمسارات `Guards (JWT & RBAC)` لمنع الوصول غير المصرح به.
2. إضافة مكاتب التحقق من البيانات `class-validator` داخل الـ DTOs.
3. معالجة رفع الملفات `File Uploads` للصور.
4. تطبيق الـ Pagination & Filtering في الاستعلامات.
